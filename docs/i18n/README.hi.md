# Dream Bot · 梦 Bot

Dream Bot बातचीत, फ़ाइलें और ब्राउज़र प्रोफ़ाइल आपके सर्वर पर रखता है। छोटा होस्ट गेटवे हमेशा उपलब्ध रहता है। काम के लिए अधिकतम एक Docker कंटेनर बनता है और सुरक्षित रूप से 300 सेकंड निष्क्रिय रहने पर हट जाता है। ब्राउज़र, मैन्युअल नियंत्रण और फ़ाइल पूर्वावलोकन बातचीत के अंदर खुलते हैं।

## सुविधाएँ

- स्थायी बातचीत और अलग कार्य रिकॉर्ड, स्पष्ट स्वीकृति तथा अनिश्चित बाहरी परिणामों की जाँच।
- वास्तविक Chromium, फ़ाइल संचालन, पुष्टि की गई स्मृति, समयबद्ध कार्य और एन्क्रिप्टेड बैकअप।
- Chat Completions / Responses संगत API और कॉन्फ़िगर किए जा सकने वाले चीनी प्रदाता। Token/Coding Plans के लिए प्रदाता की वास्तविक अनुमति आवश्यक है; प्रोटोकॉल की संगतता उपयोग का अधिकार नहीं सिद्ध करती।
- स्वचालित पढ़ना, SSE और केवल देखना कंटेनर को शुरू नहीं करते और उसका जीवन नहीं बढ़ाते। स्थायी डेटा प्रक्रिया की मेमोरी का स्नैपशॉट नहीं है।

इंटरफ़ेस, बैकएंड, होस्ट प्रबंधन, सैंडबॉक्स, डिप्लॉयमेंट और परीक्षणों का पूरा मौलिक कोड MIT के अंतर्गत खुला है। कोई अलग बंद नियंत्रण सेवा नहीं है। मॉडल सेवाओं पर शुल्क लग सकता है और तृतीय-पक्ष लाइसेंस लागू रहते हैं।

## स्थापना और स्थिति

वर्तमान लक्ष्य Linux amd64, systemd/cgroup v2, Docker और AppArmor, Landlock, seccomp तथा Chromium user namespaces वाला कर्नेल है। कम से कम 4 GB RAM सुझाई जाती है। मुख्य तकनीकें Go, Python, TypeScript/React और SQLite हैं।

यह प्रयोगात्मक स्रोत रिलीज़ है। स्वतंत्र साफ़ स्थापना, ARM64 और प्रदाता, विफलता व पुनर्स्थापन की पूरी जाँच अभी बाकी है। ऐप का इंटरफ़ेस मुख्यतः चीनी में है; ये अनुवाद दस्तावेज़ों के हैं। साझा शुरुआती पासवर्ड या उत्पादन क्रेडेंशियल शामिल नहीं हैं।
