# Dream Bot · 梦 Bot

**Персональный агент для собственного сервера: постоянные диалоги и временная среда выполнения.**

Dream Bot хранит диалоги, файлы и профиль браузера на вашем сервере. Небольшой шлюз работает постоянно; для задач создаётся не более одного контейнера Docker, который удаляется после 300 секунд безопасного простоя. Просмотр браузера, ручное управление и предпросмотр файлов доступны прямо в диалоге.

## Возможности

- Постоянные диалоги и отдельные записи выполнения, явные разрешения и сверка неопределённых внешних результатов.
- Настоящий Chromium, обработка файлов, подтверждённая память, расписания и зашифрованные резервные копии.
- Настраиваемые API Chat Completions / Responses, включая китайских поставщиков. Token/Coding Plans требуют разрешённого использования; совместимость протокола не подтверждает права по подписке.
- Автоматическое чтение, SSE и просмотр без управления не запускают контейнер и не продлевают его жизнь. Постоянные данные — не снимок оперативной памяти.

Весь собственный код интерфейса, сервера, управления хостом, песочницы, развёртывания и тестов открыт под MIT. Отдельной закрытой управляющей платформы нет. Услуги моделей могут быть платными, а зависимости сохраняют свои лицензии.

## Установка и статус

Текущая платформа: Linux amd64, systemd/cgroup v2, Docker и поддержка AppArmor, Landlock, seccomp и пространств имён Chromium. Рекомендуется от 4 ГБ ОЗУ. Стек: Go, Python, TypeScript/React, SQLite.

Экспериментальный выпуск исходников. Независимая чистая установка, ARM64 и полная матрица поставщиков, сбоев и восстановления ещё не проверены. Интерфейс в основном на китайском; переводы относятся к документации. Общих начальных паролей и рабочих учётных данных нет.
